CS6220 Homework 2 scaffold for data mining experiments on linear regression and regression trees.

## Setup

1. Create a virtual environment: `python3 -m venv .venv`
2. Install dependencies: `.venv/bin/pip install -r requirements.txt`
3. Register the Jupyter kernel: `.venv/bin/python -m ipykernel install --user --name cs6220_HW2 --display-name "cs6220_HW2"`
4. Start JupyterLab: `.venv/bin/jupyter lab`
5. Open `homework_2.ipynb`
6. Run All
